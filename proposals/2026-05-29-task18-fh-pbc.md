# Proposal: Task 18 — Periodic boundary conditions for `FermiHubbard1D`

## Approach

Add `periodic: bool = False` to `FermiHubbard1D.__init__` and thread it to
`_build_fh_terms`. When `periodic=True`, append two long-string `HamiltonianTerm`s
— one per spin species — after the bulk bonds. Trotter groups gain a 6th entry for
these boundary bonds.

## JW string derivation for boundary hops

**Boundary hop:** $c^\dagger_{L-1,\sigma} c_{0,\sigma} + \text{h.c.}$

In JW: $c^\dagger_{L-1} c_0 + \text{h.c.} = -\tfrac{1}{2}[ X_0\, Z_1 \cdots Z_{L-2}\, X_{L-1} + Y_0\, Z_1 \cdots Z_{L-2}\, Y_{L-1} ]$

The string spans all qubit indices between site 0 and site L-1 in the register.

**Stacked ordering** (`[↑_0 … ↑_{L-1}, ↓_0 … ↓_{L-1}]`):

- Spin-↑ boundary: qubits [0, 1, …, L-1].  
  Local obs: `PauliSum(["X"+"Z"*(L-2)+"X", "Y"+"Z"*(L-2)+"Y"])` with coeff −t/2.  
  This is weight-L (L qubits involved). For L=2 this degenerates to "XX"/"YY" — identical to the bulk bond, correctly doubling the hopping for the 2-site ring.

- Spin-↓ boundary: qubits [L, L+1, …, 2L-1]. Same local obs.

**Interleaved ordering** (`[↑_0, ↓_0, ↑_1, ↓_1, …]`):

- ↑_{L-1} sits at qubit 2(L-1) = 2L-2; ↑_0 at qubit 0.  
  JW string spans qubits 0 … 2L-2 (n-2 = 2L-2 total sites).  
  Local obs on qubits [0, 1, …, 2L-2]: `"X"+"Z"*(2L-3)+"X"` / `"Y"+"Z"*(2L-3)+"Y"`, coeff −t/2.

- ↓_{L-1} at qubit 2L-1; ↓_0 at qubit 1.  
  JW string spans qubits 1 … 2L-1.  
  Local obs on qubits [1, 2, …, 2L-1]: same Pauli structure.

## Implementation (~15 lines in `_build_fh_terms`)

```python
if periodic:
    if num_fermions < 2:
        raise ValueError("periodic=True requires num_fermions >= 2.")
    L = num_fermions
    if ordering == "stacked":
        pbc_local = PauliSum([
            PauliString("X" + "Z" * (L - 2) + "X", -t / 2),
            PauliString("Y" + "Z" * (L - 2) + "Y", -t / 2),
        ])
        up_boundary = HamiltonianTerm(list(range(L)), pbc_local)
        down_boundary = HamiltonianTerm(list(range(L, 2 * L)), pbc_local)
    else:  # interleaved
        pbc_local = PauliSum([
            PauliString("X" + "Z" * (2 * L - 3) + "X", -t / 2),
            PauliString("Y" + "Z" * (2 * L - 3) + "Y", -t / 2),
        ])
        up_boundary = HamiltonianTerm(list(range(2 * L - 1)), pbc_local)
        down_boundary = HamiltonianTerm(list(range(1, 2 * L)), pbc_local)
    boundary_bonds = [up_boundary, down_boundary]
else:
    boundary_bonds = []
```

The `trotter_groups` list gets a 6th entry: `boundary_bonds` (may be empty for OBC).

`_build_fh_terms` returns `up_bonds + down_bonds + onsite + boundary_bonds`.

### Analytical check: free PBC tight-binding at L=4, half-filling

PBC dispersion: $\varepsilon_k = -2t\cos(2\pi k / L)$ for $k = 0, 1, \ldots, L-1$.

For L=4: $\{-2t,\, 0,\, 2t,\, 0\}$. Two electrons per spin fill the two lowest levels
($-2t$ and $0$). Ground energy per spin = $-2t$; total = $-4t$.

This is independent of ordering and robust to numerical noise — a clean regression target.

## Edge cases

- **L=2, stacked PBC:** boundary term is "XX"/"YY" on sites [0,1] — same structure as the
  existing bulk bond. Adding it doubles the hopping, which is physically correct (2-site ring
  has two paths between sites). No special case needed.
- **L=1:** raises `ValueError` in the PBC branch before touching any term construction.
- **Trotter with PBC:** boundary bonds are long-range; they can't be merged with even/odd
  bulk layers without introducing Trotter error. They form their own group and can be applied
  together (↑ and ↓ boundary bonds act on disjoint sets of qubits). Trotter quality with PBC
  is not tested here — that's a future concern.
- **`_embed_local_obs`:** already handles arbitrary-length PauliStrings; no changes needed.
