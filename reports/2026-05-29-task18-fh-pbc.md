## What was accomplished

Single new parameter added to `FermiHubbard1D`:

```python
class FermiHubbard1D(Hamiltonian):
    def __init__(
        self,
        num_fermions: int,
        t: float = 1.0,
        U: float = 1.0,
        mu: float = 0.0,
        ordering: str = "stacked",
        periodic: bool = False,      # new
    ): ...
```

When `periodic=True`, `_build_fh_terms` appends two `HamiltonianTerm`s (one per spin species)
to `terms` and a 6th Trotter group (`boundary_bonds`):

| ordering | spin | sites | Pauli string |
|---|---|---|---|
| stacked | ↑ | [0, 1, …, L-1] | X Z^{L-2} X (weight L) |
| stacked | ↓ | [L, L+1, …, 2L-1] | X Z^{L-2} X |
| interleaved | ↑ | [0, 1, …, 2L-2] | X Z^{2L-3} X (weight 2L-1) |
| interleaved | ↓ | [1, 2, …, 2L-1] | X Z^{2L-3} X |

All existing code paths (`as_matrix`, `as_observable`, `ground_state`, `trotter_circuit`) work
unchanged. The 6th Trotter group is empty for OBC (`boundary_bonds = []`) and is filtered
out by `trotter_circuit`'s `[g for g in self.trotter_groups if g]`.

5 new tests, all passing (total 15/15 for the FH suite):
